# Zotero AI Reader

> 在 Zotero 里选几页，直接在原文旁看中文译文。

Zotero AI Reader 是面向 Zotero 10 的 AI 论文精读插件。它只翻译你指定的 PDF 页面，把段落译文和一句话摘要叠加在原文位置；不用导出 PDF，不用切换网页，也不会修改你的原始论文。

[下载最新版 XPI](https://github.com/LeyangGu/zotero-ai-reader/releases) · [查看更新日志](CHANGELOG.md) · [隐私说明](PRIVACY.md)

## 为什么适合读论文

- **按需翻译，不浪费 Token**：支持 `1-8,10,12-15` 这样的页码范围，只向 AI 发送你选择的正文段落。
- **原文译文一一对应**：译文悬浮在对应段落旁，保留原文阅读节奏，并附一句话摘要，适合快速判断一段在讲什么。
- **读过一次，下次秒开**：译文保存在本地独立缓存中；重新打开 PDF 会自动显示，命中缓存时不再调用模型。
- **公式可以直接带走**：选择需要的公式，一键复制为 Obsidian 兼容 Markdown，区分行内与块级公式。
- **带着全文向 AI 追问**：在段落浮层中复制整篇 PDF，上传到 ChatGPT 后再复制当前段落的自定义提问。
- **长文也能放心跑**：翻译可收起到后台，显示页码、段落与批次进度；支持取消、失败重试和断点保留已完成结果。
- **自由选择 AI 服务**：内置 DeepSeek、OpenAI、OpenRouter、硅基流动和 Ollama，也可保存多个自定义 OpenAI 兼容地址。

## 为什么默认选择 DeepSeek

**读 10 页论文，通常只要几分钱到一毛钱左右。** 插件默认使用 `deepseek-flash`：它的 API 公开定价非常低，且支持本插件需要的 JSON 输出。我们关闭思考模式，只为翻译本身付费，不把 Token 花在冗长推理上。

以一篇文字密度普通的英文论文为例，翻译 10 页约会产生 **1 万输入 Token + 1 万输出 Token**。按 DeepSeek Flash 当前公开价格、汇率按 `1 USD ≈ ¥7.1` 粗略换算：

| 使用时段 | 估算费用（10 页） | 适合什么情况 |
| --- | --- | --- |
| 非高峰 | 约 **¥0.05** | 批量处理、对费用更敏感时 |
| 高峰 | 约 **¥0.11** | 随时翻译、即时阅读时 |

实际金额会随论文文字密度、译文长度、重试次数、缓存命中和汇率变化；图表多或文字少的论文通常更便宜。已翻译过的段落直接命中本地缓存，费用为 **¥0**。价格以 [DeepSeek 官方定价](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/) 为准（本说明更新于 2026-09-16）。

## 30 秒开始使用

1. 下载 [最新 `.xpi` 安装包](https://github.com/LeyangGu/zotero-ai-reader/releases)，要求 Zotero `10.0.2+`。
2. 在 Zotero 中打开“工具 → 插件”，点击齿轮图标，选择“从文件安装插件”，选中下载的 XPI。
3. 打开一篇 PDF，点击阅读器顶部的“AI 翻译”，选择 AI 服务和模型；云端服务首次使用时需填写对应 API Key。
4. 输入要翻译的页码，开始翻译；完成后直接在原文旁阅读中文译文。

遇到需要结合全文理解的段落时：先在译文浮层点击“复制整篇 PDF”，到 ChatGPT 按 `Ctrl+V` 上传；再回到 Zotero 点击“复制提问”，将问题粘贴到对话中。两次复制必须按此顺序，因为后一次会覆盖系统剪贴板。

API 配置可在“设置 → Zotero AI Reader”中管理。插件可从 `/models` 加载模型，也允许手动填写模型 ID。每个配置的 API Key 独立保存在 Zotero/Firefox 的加密登录存储中，不会写入普通设置或译文缓存。

“复制提问”默认带入英文原文。点击“AI 翻译”弹窗右上角的齿轮，即可切换为中文译文或中英对照，并使用 `{content}`、`{original}`、`{translation}`、`{summary}` 和 `{page}` 自定义模板。该设置也保留在 Zotero 的插件设置页中。

Ollama 默认使用 `http://localhost:11434/v1`，无需 API Key。自定义公网地址必须使用 HTTPS；本机、私有 IP 和 `.local` 局域网服务可使用 HTTP。

## 你会看到什么

| 场景 | 插件会做什么 |
| --- | --- |
| 只想读论文的第 3–6 页 | 仅提取并翻译这些页的正文，跳过参考文献、页码和重复页眉页脚。 |
| 关闭 PDF 后再打开 | 自动识别本地译文并显示，不需要再次点击翻译或支付 API 费用。 |
| 某一段翻译失败 | 只重试出错段落，已经成功的内容会立即保留。 |
| 想把公式记到 Obsidian | 勾选公式后复制为 Markdown；引文、DOI、图表编号等不会被误当成公式。 |
| 想让 ChatGPT 结合全文解释一段话 | 先复制并粘贴整篇 PDF，再复制根据当前段落生成的自定义提问。 |

## 隐私与费用

- 仅在你点击“开始翻译”后，才会把所选页面中未命中缓存的正文段落发送到当前选择的 AI 服务。
- 不修改原 PDF，不读取 cookie，不启动本地服务，也不收集遥测数据。
- “复制整篇 PDF”只访问本地附件并写入本机剪贴板；只有你主动粘贴或上传后，目标服务才会收到该 PDF。
- API Key、原文和译文不会写入日志；缓存和密钥的详细规则见[隐私说明](PRIVACY.md)。
- 云端 AI API 可能产生费用。请确认你有权将所选论文内容发送给当前服务商。

## 开发与贡献

Node.js 仅用于开发、测试和打包，普通用户无需安装。

```powershell
npm install
npm test
npm run build:xpi
```

完整贡献流程见 [CONTRIBUTING.md](CONTRIBUTING.md)，缓存兼容约定见 [CACHE_FORMAT.md](CACHE_FORMAT.md)。

本项目为独立开源项目，与 Zotero 及任何 AI 服务商均无隶属或官方背书关系。
